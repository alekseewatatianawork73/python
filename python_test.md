## Задача 1. Анкета ученика
Каждому ученику необходимо заполнить анкету о себе. Даны следующие данные: имя и фамилия ученика, его возраст и средний балл за год обучения. Причём средний балл может быть дробным числом. Вам нужно вывести анкету ученика в следующем виде:
"ФИ ученика - [фамилия и имя], возраст ученика - [возраст] лет, средний балл равен [средний балл]."

**Пример:**

Входные данные:
```
Шолохов Пётр
15
4.37
```
Выходные данные:
```
ФИ ученика - Шолохов Пётр, возраст ученика - 15 лет, средний балл равен 4.37.
```

## Задача 2. Пицца на всех
Татьяна с друзьями решили заказать себе пиццу под просмотр фильма. Им привезли **N** пицц, разделённых на **K** равных кусков. Помогите рассчитать, сколько кусков достанется каждому и сколько останется лишних, если пиццы нужно разделить поровну на **M** человек.

**Входные данные:** три целых положительных числа через пробел — количество пицц **N**, количество кусков в одной пицце **K** и число людей **M**.

**Выходные данные:** выведите два числа — количество кусков, доставшихся каждому, и количество оставшихся кусков.

**Пример:**

Входные данные:
```
3
6
4
```
Выходные данные:
```
4
2
```

## Задача 3. Счастливое число

**Пример 1:**

```

## Задача 4. Покупка новогодних шаров
Татьяна хочет украсить новогоднюю ёлку. Ей нужно купить **N** елочных шариков в магазине, и у неё есть 2 варинта, как это сделать:

- купить поштучно: по **K** рублей за 1 шарик
- закупать упаковками по **M** шаров в упаковке, по цене **X** рублей за упаковку (важно: шариков в итоге можно купить и больше, чем **N** штук)

Сначала вводится информация об **N**, **K**, **M**, **X** - все эти целые числа вводятся в одной строке. Требуется вывести, какой вариант выгоднее: 1 или 2 (то есть что выйдет дешевле). Если оба одинаково выгодны, выведите 3.

Для большего понимания смотрите тесты ниже:

**Пример 1:**

Входные данные:
```
32 3 5 10
```
Выходные данные:
```
2
```
__Пояснение к примеру 1:__

_Нужно купить N = 32 елочных шарика. Первый вариант: K = 3, если покупать поштучно, что это будет стоить 32 * 3 = 96 руб. Теперь рассмотрим второй вариант: M = 5, X = 10. Мы можем покупать упаковками по 5 елочных шаров в упаковке, тогда, чтобы купить 32 шарика, нам понадобится 7 упаковок (7 * 5 = 35, будет  3 лишних шарика, но ничего страшного). Это стоит 7 * 10 = 70 руб. То есть второй вариант оказался выгоднее первого: 70 < 96._

**Пример 2:**

Входные данные:
```
30 3 5 15
```
Выходные данные:
```
3
```

## Задача 5. Максимум среди нечётных
Дана последовательность целых чисел, каждое число вводится в отдельной строке. Минимальное возможное число = -1000, максимальное = 1000. Сколько чисел - неизвестно, но известно, что последовательность заканчивается числом 0. Найдите максимум среди нечётных чисел последовательности и выведите его. Гарантируется, что в последовательности будет хотя бы одно нечетное число.

**Пример 1:**

Входные данные:
```
100
1
24
46
5
3
0
```
Выходные данные:
```
5
```

**Пример 2:**

Входные данные:
```
67
8
4
28
79
5
0
```
Выходные данные:
```
79
```

## Задача 6. Счастливый билет
В общественном транспорте счастливым считается билет, у которого сумма первых трёх цифр равна сумме последних трёх. Татьяна хочет проверить, счастливый ли ей попался билет.

Напишите программу, которая запрашивает шестизначное число **N** (номер билета) и определяет, является ли он счастливым. Выведите «**_Счастливый билет!_**» или «**_Обычный билет_**».

**Пример 1:**

Входные данные:
```
123456
```
Выходные данные:
```
Обычный билет
```

**Пример 2:**

Входные данные:
```
915726
```
Выходные данные:
```
Счастливый билет!
```

Для большего понимания смотрите тест ниже:

**Пример:**

```

```

279
```

## Задача 10. Организация олимпиад
Татьяна занимается организацией олимпиад для школьников. Ей нужно составить расписание так, чтобы две олимпиады не проходили в один день, если ученики участвуют в обоих из них. Помогите Татьяне определить, какие ученики одновременно примут участие и в олимпиаде по истории, и в соревновании по программированию. 

В первой строке дан список учеников, участвующих в соревновании по программированию, во второй строке - ученики, участвующие в олимпиаде по истории. Выведите имена учеников, которые участвуют в обоих олимпиадах одновременно и их количество.

**Пример:**

Входные данные:
```
Tom Alex Emma Lily John
Mia Tom Lily James William
```
Выходные данные:
```
Tom Lily
2
```

## Задача 11. Чётные дни тренировок
Иван готовился к соревнованиям по бегу в течение **N** дней и записывал, сколько километров он пробегает каждый день. Тренер попросил его посчитать, сколько километров он пробежал за чётные дни (2-й, 4-й, 6-й и так далее), чтобы оценить нагрузку.

Вам дано количество дней пробежки **N** и список расстояний на каждый день с 1-го по N-ый. Выведите сумму расстояний, преодолённых Иваном в чётные дни.

**Пример:**

Входные данные:
```
11
7 9 31 4 12 11 5 9 15 8 10
```
Выходные данные:
```
41
```
