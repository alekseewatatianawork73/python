## Задача 1. Функция приветствия
Татьяна пишет программу для электронной библиотеки. При входе система должна приветствовать пользователя по имени. Напишите функцию _**greet(name)**_, которая принимает имя и **выводит** приветствие. Затем вызовите её, запросив имя у пользователя.

**Пример:**

Входные данные:
```
Анна
```
Выходные данные:
```
Привет, Анна! Добро пожаловать в библиотеку.
```

## Задача 2. Чётное или нечётное?
На уроке информатики нужно определить, является ли число чётным. Напишите функцию _**is_even(n)**_, которая **возвращает** _True_, если число чётное, и _False_ — если нечётное. Запросите число в основной программе и выведите результат ("**чётное**" или "**нечётное**"), используя условие.

**Пример:**

Входные данные:
```
7
```
Выходные данные:
```
нечётное
```

## Задача 4. Банковские операции
Иван открыл банковский счёт. Он хочет написать программу, которая позволяет пополнять счёт и снимать деньги. Баланс хранится в глобальной переменной. Напишите программу с глобальной переменной **balance**, которая изначально равна 1000. Напишите две функции:

- **deposit(amount)** — увеличивает баланс на указанную сумму;

- **withdraw(amount)** — уменьшает баланс на указанную сумму.

Вызовите функции в программе по примерам и выведите итоговый баланс.

**Обратите внимание!** Функции withdraw и deposit ничего не возвращают, они лишь меняют глобальный баланс.

Примеры (итоговый баланс после вызова функций):

**Пример 1:**

Вызовы:
```
deposit(5000)
withdraw(2000)
deposit(1000)
```
Выходные данные:
```
5000
```

**Пример 2:**

Вызовы:
```
withdraw(500)
deposit(7000)
deposit(1500)
withdraw(2000)
```
Выходные данные:
```
7000
```

## Задача 6. Каталог книг
Татьяна составляет каталог книг в электронной библиотеке. При этом она хочет сортировать книги не по алфавиту, а по длине названий — от коротких к длинным. Напишите программу, которая запрашивает названия книг через запятую и сортирует их по длине (считаются все символы строки, включая пробелы).

<details>
  <summary><b>Подсказка.</b></summary>
  1. Используйте для сортировки функцию _sorted()_ и ее дополнительный параметр - ключ сортировки.
  
  2. Для разделения названий книг по запятым и пробелам воспользуйтесь параметром функции _split()_.
</details>

**Пример:**

Входные данные:
```
Война и мир, Преступление и наказание, Анна Каренина
```
Выходные данные:
```
Война и мир, Анна Каренина, Преступление и наказание
```

## Задача 7. Допуск на аттракцион
Татьяна работает в парке развлечений и проверяет допуск посетителей на новый аттракцион. По правилам безопасности на аттракцион пускают только тех, чей рост не меньше 150 см. Татьяна записала в журнал имя и рост каждого посетителя. Помогите ей отобрать тех, кто может пройти на аттракцион.

**Входные данные:**

- В первой строке дано целое число N — количество посетителей.
- Следующие N строк содержат пары значений: имя и рост посетителя через пробел.

**Выходные данные:**

Выведите имена посетителей с ростом ≥ 150 см. Для решения используйте функцию _filter()_.

<details>
  <summary><b>Подсказка.</b></summary>
  Для хранения информации о посетителях используйте структуру Словарь. Определите, что будет являться ключом словаря, а что значением (учитывая, что рост у нескольких посетителей может быть одинаковым).
</details>

**Пример:**

Входные данные:
```
5
Анна 155
Иван 148
Татьяна 162
Сергей 150
Пётр 140
Дмитрий 171
```
Выходные данные:
```
Анна Татьяна Сергей Дмитрий
```

## Задача 8. Проверка надёжности паролей
Иван работает в системе регистрации пользователей. Он получил список всех сохранённых паролей и хочет проверить, являются ли они надёжными. Пароль является надёжным, если его длина составляет **не менее** 8 символов.

Напишите программу, которая проверяет, все ли пароли в списке являются надёжными.

**Примечание.** Для решения используйте функцию **_any()_**.

**Входные данные:**

- В первой строке дано целое число N — количество паролей, полученных от пользователей.
- Следующие N строк содержат различные пароли.

**Выходные данные:**

Выведите "_Все пароли надёжны_" или "_Найдены ненадёжные пароли_" в зависимости от результата программы.

**Пример 1:**

Входные данные:
```
3
qwerty123
password1
abcdefgh
```
Выходные данные:
```
Все пароли надёжны
```

**Пример 2:**

Входные данные:
```
5
python567
pass
abcdefgh
12345678
longpassword
```
Выходные данные:
```
Найдены ненадёжные пароли
```
